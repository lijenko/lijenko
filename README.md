## 📂 Projetos em destaque

### 🧾 Ecossistema WTX — Sistemas Fiscais e Tributários em produção
Conjunto de sistemas web para escritórios de consultoria tributária, construídos sobre uma **stack
padronizada** (Node.js · Express · tRPC 11 · Drizzle ORM · MySQL 8 · React 19 · Vite · Tailwind 4 ·
shadcn/ui · Vitest · pnpm) e uma **pipeline de deploy compartilhada** (typecheck → testes → build →
migrations → dreno de conexões → troca de versão → smoke test com rollback automático).

| Sistema | O que faz |
|---|---|
| **WTX Users** — [wtxuser.com.br](https://wtxuser.com.br) | Hub central de **autenticação e autorização** (SSO por redirect + ticket de uso único, controle por usuário e por escritório, bcrypt + sessão por token opaco) usado por todos os sistemas abaixo |
| **Extrator Fiscal** — [extrator-fiscal.com.br](https://extrator-fiscal.com.br) · [sistema](https://sistema.extrator-fiscal.com.br) | Extração de **100+ relatórios em Excel** a partir de SPED Fiscal, SPED Contribuições, CAT 83/207 e XML de NF-e/CT-e, com motor de regras e fórmulas por contribuinte e processamento em segundo plano |
| **CAT 42** | Apuração de **ressarcimento e complemento de ICMS-ST** (Portaria CAT 42/2018 – SEFAZ/SP): importação de NF-e/NFC-e/CF-e/SPED, custo médio ponderado móvel e geração do arquivo no leiaute oficial |
| **CAT 207** — [wtxcat207.com.br](https://wtxcat207.com.br) | Reimplementação do **e-CredAc** para crédito acumulado de ICMS: cálculo de IVA/PMC, classificação nas Fichas 6A–6F, DGCA e arquivo digital LASIMCA |
| **CIAP Eletrônico** | Identificação e recuperação de **créditos extemporâneos de ICMS sobre ativo imobilizado**, com geração e inserção do **Bloco G** no SPED Fiscal |
| **PER/DCOMP Generator** | Geração do arquivo oficial **PER/DCOMP** (Receita Federal) a partir de DIRF, SPED, NF-e e planilhas, com tenancy por escritório |
| **Exclusão ICMS × PIS/COFINS** | Recuperação tributária conforme **Tema 69 do STF**: ETL por item (NF-e × EFD) com janelas temporais, validação QA de tolerância zero, EFD retificador e relatórios de auditoria |

> 🔒 Os repositórios são privados por conterem regras de negócio e dados de clientes.
