### ☁️ Migração de Infraestrutura para a Nuvem
Planejamento e execução da migração de uma aplicação em produção (antes hospedada em
plataforma gerenciada) para uma **arquitetura em nuvem com camadas separadas** de aplicação
e banco de dados.

- Implantação de PostgreSQL, Redis, PgBouncer e Docker em servidor Linux/cloud

- GitHub Actions, reverse proxy, health checks e práticas de observabilidade
- **Stack:** Cloud · Linux · PostgreSQL · Redis · PgBouncer · Docker · Cloudflare · CI/CD
